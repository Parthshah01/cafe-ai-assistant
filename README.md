# ☕ Cafe AI Assistant

A modern AI-powered cafe website integrated with an intelligent chatbot assistant for customer interaction, menu recommendations, and smart support.

## 🚀 Features
- AI Chatbot Integration
- Interactive Cafe Website
- Smart Menu Recommendations
- Responsive UI Design
- Fast and Modern Interface

## 🛠️ Tech Stack
- React
- TypeScript
- Tailwind CSS
- Node.js
- AI Chatbot API

## 📂 Project Structure
- Frontend
- Backend
- AI Chatbot Integration
- Menu Management

## 💡 Purpose
This project demonstrates how AI can enhance customer experience in cafe and restaurant websites through intelligent conversations and automated assistance.
